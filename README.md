# Customer Churn Prediction Using Deep Learning

## Project Overview
This project predicts whether a customer is likely to leave a telecommunications company using an Artificial Neural Network (ANN).

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- TensorFlow and Keras
- Jupyter Notebook

## Project Workflow
1. Data Loading
2. Data Cleaning
3. Exploratory Data Analysis
4. Data Preprocessing
5. ANN Model Building
6. Model Training
7. Model Evaluation
8. Customer Churn Prediction

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1 Score
- ROC-AUC

## Dataset
IBM Telco Customer Churn Dataset

Source: https://www.kaggle.com/datasets/blastchar/telco-customer-churn
